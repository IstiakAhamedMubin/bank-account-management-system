
# Bank Account Management System (Based on real life Banking system)

This is my mini project of Java Oops, about banking management system.
A Java-based Bank Account Management System developed to demonstrate Object-Oriented Programming (OOP) concepts and exception handling.

## Features

* Create bank accounts
* Deposit funds
* Withdraw funds
* Calculate account interest
* Display account information
* Custom exception handling for insufficient funds
* Validation for invalid account operations

## OOP Concepts Used 

* Encapsulation
* Inheritance
* Abstraction
* Method Overloading
* Exception Handling
* Custom Exception

## Project Structure

* `Account.java` - Abstract parent class
* `BankAccount.java` - Base bank account implementation
* `SavingsAccount.java` - Savings account with interest calculation
* `CurrentAccount.java` - Current account implementation with interest calculation
* `InsufficientFundsException.java` - Custom exception class
* `Main.java` - Driver class for testing the system

## Technologies

* Java
* IntelliJ IDEA

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Compile and run `Main.java`.

## Learning Objectives

This project was created as part of a Java OOP learning exercise to practice class design, inheritance, abstraction, and exception handling.
